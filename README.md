# Keqi’s Demos

Selected projects in agent systems, multimodal generation, and mechanistic interpretability.

- [Rhythm-Agent — 创意广告短视频剪辑 Agent（阿里实习）](https://ckqqqq.github.io/Demo/Rhythm-Agent1/)
  - 简单 Agent loop、多模态工具与丰富数据，生成音乐驱动的多镜头视频。
- [DataJarvis (prev. Kingfisher) — 数据分析与 SQL Agent（微软实习）](https://ckqqqq.github.io/Demo/DataJarvis/)
  - Agent–SQL 协议、执行反馈与自我修正；分析耗时由 1–2 天缩短至 20 分钟。
